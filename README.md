# La Palabra de Dios

Página de vendas independente do aplicativo principal.

## Publicação gratuita na Vercel

1. Crie um repositório vazio no GitHub chamado `la-palabra-de-dios`.
2. Conecte este repositório local ao GitHub.
3. Na Vercel, importe o repositório e publique sem comando de build: a página é estática.
4. A URL gratuita ficará no formato `https://la-palabra-de-dios.vercel.app`.

Os botões de compra já apontam para o checkout da Hotmart configurado na página.
